# 📁 Website Images — Drop & Go Guide

All images for the Rotaract Club of Bharuch website live here.
**Just drop files in the right folder and push to Git — the website updates automatically.**

---

## Folder Map

```
public/
│
├── logo.png                  ← Club logo (replace to update everywhere)
├── president.jpeg            ← President photo
│
├── team/                     ← Board member photos
├── projects/                 ← Project photos (one sub-folder per project)
├── events/                   ← Event photos (one sub-folder per event)
├── gallery/                  ← General gallery / lightbox photos
├── sponsors/                 ← Sponsor logos
└── intro/                    ← Background collage photos (Who We Are section)
```

---

## Quick How-To per Section

| Section | Folder | What to do |
|---|---|---|
| **Team photos** | `team/` | See `team/README.md` |
| **Project photos** | `projects/<slug>/` | See `projects/README.md` |
| **Event photos** | `events/<slug>/` | See `events/README.md` |
| **Gallery** | `gallery/` | See `gallery/README.md` |
| **Sponsor logos** | `sponsors/` | See `sponsors/README.md` |
| **Intro collage** | `intro/` | Drop any `.jpg`/`.png` here to add to background collage |

---

## Accepted Formats
`.jpg` · `.jpeg` · `.png` · `.webp`

> **Tip:** Use `.webp` for best performance. Compress images to < 500 KB each before uploading.
